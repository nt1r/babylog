# 手机桌面安装 BabyLog 教程（iPhone & 安卓）

把 BabyLog 添加到手机桌面后，就能像普通 App 一样**点图标直接全屏打开**，没有浏览器地址栏，单手记一笔更顺手。

> **小提示**：如果链接是从微信 / QQ 发过来的，**请先点右上角 `···` 选择「在浏览器中打开」**，不要直接在微信里操作。

---

## 一、iPhone / iPad（iOS）

必须使用系统自带的 **Safari 浏览器**（不要用微信或 Chrome）：

1. 在 **Safari** 中打开你的 BabyLog 网址并登录。
2. 点击屏幕底部正中间的 **分享按钮**（一个带向上箭头的方框 `□↑`）。
3. 在弹出的菜单中往下滑，点击 **「添加到主屏幕」**。
4. 确认名称为 **BabyLog**，点击右上角 **「添加」** 即可。

回到手机桌面，就能看到小木马图标，点开即为全屏模式。

---

## 二、安卓手机（Android）

推荐使用 **Chrome**、**Edge** 或手机自带浏览器：

### 方式 1：浏览器菜单添加（通用）

1. 在浏览器中打开 BabyLog 网址并登录。
2. 点击浏览器右上角（或底部）的 **菜单图标**（`⋮` 或 `☰`）。
3. 点击 **「安装应用」** 或 **「添加到主屏幕」**。
4. 在弹窗中点击 **「安装」** 或 **「添加」** 完成。

### 方式 2：应用内一键安装（Chrome / Edge 支持）

- 登录后打开左侧菜单进入 **「偏好与账号」**，若页面中出现 **「添加到桌面」** 按钮，直接点击并确认即可。

---

## 常见问题

- **安卓点了「添加到主屏幕」但桌面没出现图标？**  
  小米、华为、OPPO、vivo 等手机默认可能关闭了浏览器的桌面快捷方式权限。前往手机 **「设置 → 应用管理 → 找到对应浏览器 → 权限管理」**，开启 **「桌面快捷方式」** 后再添加一次即可。
- **为什么安卓里只显示「添加快捷方式」而不是「安装应用」？**  
  请确认访问地址是以 `https://` 开头的安全网址；普通 `http://` 地址只能添加网页快捷方式，无法以独立全屏 App 形态运行。
- **以后服务升级了需要重新安装吗？**  
  **不需要。** 服务器更新后，重新打开桌面图标会自动加载最新版本。
