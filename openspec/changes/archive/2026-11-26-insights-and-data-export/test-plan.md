# Test Plan

遵循 [AGENTS.md](../../../AGENTS.md) 与 [docs/testing-guide.md](../../../docs/testing-guide.md)：常驻自动化测试仅限后端 Go 测试（纯单元测试 + 黑盒 HTTP API 全链路集成测试），零第三方测试依赖；前端纯 TS 逻辑（`insights.ts`、`growth-chart.ts` 增量计算、导出参数校验与 SVG/颜色工具）与 UI 视觉交互（390px 移动 + 桌面亮/暗态）在实施阶段通过仓库外 `$TMPDIR` 临时验证并及时清理。

| `data-export` / `Multi-sheet Excel workbook export by date range and categories` / `Export multi-sheet workbook with daily summary and selected category detail sheets`, `Export filtered category subset and sanitize spreadsheet formula prefixes` | 在 `backend/internal/integration/data_export_test.go` 新增 `TestDataExportMultiSheetXLSXAndSanitization`：通过 `Scenario` 创建含 5 类记录（跨夜睡眠、跨 UTC 日界线喂养、含 `=SUM(A1:A2)` 备注的喂养记录、尿布/洗澡、体温/用药、生长/长牙）及另一个隔离宝宝的数据，分别请求全分类自定义区间 `start=2026-11-21&end=2026-11-23&categories=feeding,sleep,care,health,growth&tz=Asia/Shanghai` 与子集 `days=7&categories=feeding,care&tz=Asia/Shanghai`，并用标准库 `archive/zip` + `encoding/xml` 断言 `.xlsx` 响应头、Sheet 列表、跨夜睡眠双日汇总值、本地时区格式化时间、仅含目标宝宝数据及公式前缀中和结果 | 返回 HTTP 200、`Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`、`Cache-Control: no-store` 与含文件名 `Content-Disposition`；全分类导出含 6 个有序 Sheet（`按日汇总` + 5 张明细表）且数值与时区准确、零跨宝宝串数；子集导出仅含 `按日汇总`、`喂养明细`、`护理明细` 且危险备注前缀已被安全转义 |

> 说明：`dashboard-insights` 下 `Multi-dimension Insights page and chart image export`、`Excel export drawer and filter controls`、`Unified Health and Growth navigation and Growth workspace` 与 `Dashboard vaccine alerts, Health Observation KPI, and Growth & Immunity cards` 属于纯前端 Web 交互规格（`The web application SHALL` / `The web dashboard SHALL`），按项目边界不纳入常驻前端自动化测试，实施阶段通过系统临时目录纯 TS 逻辑断言脚本与免登录亮/暗双态（390px 移动 + 桌面）截屏审图完成验证。
