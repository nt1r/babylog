# Proposal: 看板亲喂趋势扩展与前端信息架构和交互体验全面优化

## Why

当前前端界面存在多处面向用户的多余文案（未上线功能的研发排期话术、PWA/免签/管理员等技术或角色术语、列表与抽屉内重复说明书式提示）以及高频育儿场景下的体验痛点（移动端一键直记排在最底端、录入抽屉报错隐藏在底部、纯亲喂家庭趋势图每天显示 0 ml、窄屏标签溢出与记录行误触风险）。本次变更通过扩展趋势接口支持亲喂维度并同步精简重构前端交互与文案，让单手育儿记录更直接、清晰、可靠。

## What Changes

- **后端趋势契约扩展**：`GET /api/dashboard/trends` 的 `daily` 数组每日项新增 `direct_breast_min`（当日亲喂总分钟数）与 `direct_breast_count`（当日亲喂次数），复用共享喂养聚合函数确保与今日 KPI 及列表小计口径一致。
- **隐藏未上线占位入口**：从侧边栏导航与快速录入抽屉暂时隐藏「提醒待办」入口，保留 `/reminders` 路由文件并清理其中的内部排期话术与无效新建入口。
- **首页看板重排与健壮性补齐**：精简问候区文案（不再直接拼接技术账号名）、将「一键直记」操作条置顶至首屏高频区、移除底部纯装饰绘本卡片、补齐看板错误重试与无数据空态；「近 7 日成长趋势」喂养维度根据近 7 日数据自动切换展示“每日奶量”或“每日亲喂时长”，并补齐一键直记撤销异常处理与默认奶量加载守卫。
- **全局壳层与列表页体验优化**：移除侧边栏常驻小贴士、消除桌面端双主色「记一笔」按钮重叠、移动端改用通用菜单图标并隐藏列表页重复标题；修复健康页窄屏 Tab 溢出；放大记录行操作按钮触控区并拉大编辑与删除间距、支持点击行主体编辑；删除弹窗展示记录时间与摘要；筛选空状态提供快捷放宽时间范围按钮。
- **录入抽屉、设置页与全站文案/单位统一**：精简录入抽屉多余说明与重复徽章、将表单错误提示固定至底部操作栏上方并补齐前端即时校验、防止睡眠类型被时间微调自动覆写；设置页独立运行态隐藏安装引导卡片并去除技术术语、修复后台刷新覆盖未保存编辑并补齐前端校验；全站统一自然中文时长、量词与全角括号单位风格。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `dashboard-insights`: 扩展 `GET /api/dashboard/trends` 的每日趋势响应字段，增加每日亲喂总分钟数（`direct_breast_min`）与亲喂次数（`direct_breast_count`），支撑前端喂养趋势在瓶喂/配方奶与纯亲喂场景下自动适配展示。

## Impact

- 后端：`backend/internal/dashboard/service.go` 及 `backend/internal/httpapi/records_dashboard_test.go`。
- 前端：看板、四类记录列表页、提醒占位页、设置页、登录与建档页、AppShell 导航、快捷录入抽屉与子表单、时间格式化与记录 API 类型定义。
- 兼容性：`/api/dashboard/trends` 仅为向后兼容的响应字段追加，不影响现有字段和调用方。
